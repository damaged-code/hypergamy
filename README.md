# hypergamy

Prints the "HYPERGAMY" diagram in your terminal using ANSI colors.

Red men fan out to many women on the left; cyan women converge on the top three men on the right.

## Usage

```bash
bash hypergamy.sh
```

Requires `awk` and a terminal at least 80 columns wide with ANSI color support.

## Note

This is an illustrative opinion graphic, not data.
